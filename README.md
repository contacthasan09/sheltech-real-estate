# Sheltech — Real Estate Developer Clone

Visual recreation of [sheltech-bd.com](https://www.sheltech-bd.com/) for portfolio use.

## Design tokens
- Ink `#08082b` · Soft navy `#212158`
- Mist `#f5f5f5` · Gray `#d6d6d6`
- Green `#2aae3d` · Display + body fonts
- Pill inputs (100px radius), soft shadows

## Routes
| Path | Page |
|------|------|
| `/` | Home |
| `/projects` | All projects |
| `/projects/residential` | Residential |
| `/projects/commercial` | Commercial |
| `/projects/sapphire` | Sapphire Series |
| `/about` | About |
| `/leaders` | Management Team |
| `/landowner` | Joint venture / landowner |
| `/media` | Media center + newsletter |
| `/customer` | Customer inquiry |
| `/sign-in` | Sign in |

## Run
```bash
cd sheltech-react
npm install
npm run dev
```
